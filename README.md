# Offline SMS Scam Guard (on-device, Llama 3.2 + ExecuTorch)

Bharat AI-SoC Challenge (2nd edition) submission by **Udgeeth Kaushik** and **Riya Maurya** (mentor: Dr. Srishti Priya Chaturvedi).

An Android app that reads SMS **fully offline**, detects scams/phishing, and explains
the threat in simple Hinglish. No cloud, no API calls. Runs on a Moto G60 (CPU only).

Built with Llama.

## Features
- **Paste mode:** paste any SMS, get risk score, detected signals, a Llama-written
  explanation and fixed "Kya karein" safety steps.
- **Auto-read:** incoming SMS is scanned in the background (~1 ms). Suspicious ones
  raise a notification with a plain-language warning.
- Works in airplane mode.

## How it works
```
SMS -> TF-IDF + Logistic Regression -> rule layer -> risk score
        flagged? -> Llama 3.2 1B (ExecuTorch) writes ONE explanation line
                 -> safety guard (length, banned phrases, claims must match detected signals)
                 -> else fixed Hinglish template
actions ("Kya karein") are always fixed text, never generated by the LLM
```
Why hybrid: a 1B LLM alone is not reliable as a classifier. The detector decides;
Llama only explains, and its output is checked before display.

## Results (preliminary)
| Item | Value |
|---|---|
| Hand-written test set (40 SMS) | 92.5% accuracy (37/40), scam recall 19/20, 2/20 legit flagged |
| Detector latency | ~1 ms |
| Safe SMS response | ~0.4 s |
| Scam SMS with Llama explanation | ~10 s (9-12 tokens/s) |
| Model load | ~2.5 s |

The test set is small and written by the authors, so treat numbers as preliminary.

## Build & run
1. Open the project in Android Studio (JDK 17).
2. Put `sms_model.json` in `app/src/main/assets/` (included).
3. Download the Llama 3.2 1B Instruct `.pte` (8da4w, XNNPACK) and `tokenizer.json`
   (not included, see the ExecuTorch Llama guide) and push them to the phone,
   then pick them in the app's model settings.
4. Run on device. For auto-read, grant the SMS permission to the app.

## Repo layout
- `app/.../SmsDetector.kt`: detector, rule layer, advisor and guard
- `app/.../SmsReceiver.kt`: background SMS scanning + notification
- `app/.../ChatViewModel.kt`: paste-mode flow and Llama generation
- `training/`: Kaggle training script and Hinglish dataset

## Limitations
- Small test set; rules were tuned on the same data.
- 1B Llama sometimes makes wrong claims; the guard falls back to a fixed template.
- Notification text uses the detector's line; Llama explanation appears in-app.
